# Etch-a-Sketch
Odin Foundations: JS + CSS + HTML , Final Assignment -01

Target: Create a dynamic canvas of square boxes that stacks themselves into a clean grid.

        1. Input: User inputs the number of boxes they want to create through an alert popup.
        2. Creation: Page creates boxes and stacks them in a neat grid using flexbox.
        3. Hover Interactions :
                    Mouse Enter
                    Mouse Leaves
                                    Color changes on hover & goes back to normal on mouse exit
        4. Bonus:   Randomize: Randomize color values through a function
                    Opacity: Number of interactions changes the opacity, interactions=10 , opacity reaches at
                    100%, increment in iterations of 10%


Task Breakdown:

    1. Create boilerplate html, with a container div
    2. Add div using js
    3. Take input for no. of boxes
    4. Add interactions
    5. Randomize color
